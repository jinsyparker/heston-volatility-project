# Sample Data

This folder stores the frozen AAPL option snapshot used by the README and `reports/run_summary.md`.

- `AAPL_canonical_surface_checked.csv`: cleaned and validated option rows, including inferred rate/dividend columns.
- `AAPL_canonical_iv_fit.csv`: smoothed implied-volatility surface used to select the calibration target.

The snapshot was saved from a Yahoo Finance option-chain pull on 2026-10-08 at 21:43 IST.
